# Data availability

The source measurements are publicly available as *Gas sensor array temperature modulation* in the UCI Machine Learning Repository (J. Burgués, 2018; https://doi.org/10.24432/C5S302) under CC BY 4.0. The accompanying reproducibility repository provides the derived numerical evidence used for the reported development and fixed-D10 temporal-confirmation analyses, including saved predictions, reference values, query masks, causal-access records, metrics, protocols and provenance hashes:

https://github.com/asayghe1/CO-Sensor-Reference-Calibration

The original raw UCI archive is obtained directly from UCI using the documented download instructions and historical checksum and is not redistributed. R7/R14 raw data and the sealed UCI270 batches are excluded.

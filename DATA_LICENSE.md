# Data license and attribution

The [official UCI dataset 487 record](https://archive.ics.uci.edu/dataset/487/gas+sensor+array+temperature+modulation), checked on 2026-10-12, lists **Creative Commons Attribution 4.0 International (CC BY 4.0)** for *Gas sensor array temperature modulation*. See the [license terms](https://creativecommons.org/licenses/by/4.0/).

UCI's displayed citation is:

> Burgus, J. (2018). Gas sensor array temperature modulation [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5S302.

The current UCI record identifies the creator as Javier Burgus. This attribution concerns the dataset; it does not imply endorsement of this manuscript by the creator or UCI.

The release includes derived numerical records: exposure features, saved predictions and references, query masks, correction/envelope states, metrics and diagnostic summaries. These were derived through the documented preprocessing, model and calibration analyses. They are not the original raw measurement archive. Their source attribution and transformation history are retained in the frozen protocols and source manifest. The dataset-derived numerical materials in this package are distributed under CC BY 4.0 with this attribution. The original project code has the separate MIT license. MIT does not override rights in the UCI data, manuscript or third-party bibliography style.

No original UCI archive, raw sensor time series, R7/R14 raw values, or UCI270 sealed batches are included. The hashes in `data/DATASET_MANIFEST.json` identify the archive previously verified by this project; they are not claimed to be publisher-provided checksums. Final author authorization for the public release and code/data-access arrangement remains outstanding.
